사각형 · 접시형 · 트레이형 + 면별 이미지·색상·선·텍스트 편집

1. 상자 형태 / 치수 (mm)

2. 면 이미지 업로드

3. 면 편집

파란 박스를 드래그하면 이동, 모서리 4개 점은 비율 고정 크기조절, 상하좌우 중간 4개 점은 그 방향으로만 폭/높이가 조절돼요.

4. 작업 저장 / 불러오기

현재 작업을 파일로 저장해 두었다가 나중에 다시 불러와 수정할 수 있어요.

5. 쇼핑몰에 연결하기

면 이미지를 "URL로 등록"한 경우에만 임베드 코드에 반영돼요. 내 컴퓨터에서 올린 파일은 브라우저 메모리에만 있어서 다른 사람 화면엔 안 보여요.
